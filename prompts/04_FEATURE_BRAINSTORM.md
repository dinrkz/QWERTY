```text
Read CASE.md, FEATURE_BACKLOG.md, and current implementation status for the Build with AI Astana assistant. Generate optional ideas without editing the application.

Prioritize relevance/usefulness, context, explanation quality, and demo clarity before novelty. Consider the brief's optional group planning, mini-routes, multilingual replies, events, and accessibility only where data supports them.

For each idea provide: user value, visible demo benefit, rubric criterion, smallest scope, source/data requirements, dependencies, estimated effort with assumptions, risk, and acceptance check. Do not invent time estimates without code/context or treat unverified amenities/events as available data.

Group proposals as AFTER CORE / BACKLOG / REJECT. Preserve time for slides, scenario documentation, and YouTube recording. Do not imply implementation approval or start building optional features.
```

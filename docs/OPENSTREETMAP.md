# Map and walking routes

The user authorized replacing the map provider on 2026-10-19. The bounded interface on port 3003 now uses Leaflet 1.9.4 with OpenStreetMap tiles, requiring no map API key. The collected places remain from 2GIS; changing the map does not change their provenance or reuse permissions. The separate legacy map adapter is retained; strict offline mode continues to prohibit external requests.

The bounded interface loads the map on opening. Hide map removes it. Choose on map explicitly enters start-picking mode; click a point, or pan with the keyboard and select Use map centre. Approximate coordinates update locally; selection clears stale results without submitting a search or spending an AI request. Picks outside supported Astana bounds are rejected, and selection is blocked during generation. Numbered result markers match sidebar cards. Names are assigned as text. Selecting a card or marker requests one pedestrian route; ordinary map clicks do not change the start. Tiles reveal the viewport and IP, disclosed beside the map. Device location remains disabled. Strict offline mode still disables external maps and routing.

The local `/api/route` relay sends only rounded start/destination coordinates to `https://valhalla1.openstreetmap.de/route`, with pedestrian costing. It sends no names, IDs, query, credentials or dataset. The route provider receives the server connection/IP. Same-origin, Host and token guards apply; bounds, response size, geometry and endpoints are validated. One route is in flight, starts are spaced by at least 1.1 seconds, deadline is 12 seconds and there are no automatic retries. Repeated selection reuses the browser's current-search cache. Changing inputs clears that cache; coordinates and geometry are not persisted by the application. Public FOSSGIS routing is best-effort. A failed route leaves cards usable and never substitutes a straight line as a street route. Provider walking time updates the displayed total, including visit, return and buffer; over-budget routes are flagged. Entrances, accessibility and current conditions remain unverified.

Leaflet JS/CSS are vendored in public/vendor/leaflet with their license. [vendor-leaflet.mjs](../scripts/app/vendor-leaflet.mjs) is the retained maintenance downloader; it checks official JS/CSS SHA-256 integrity values. Runtime code is served locally. The CSP permits only the OSM tile image host in bounded mode, with local scripts and local API connections.

The tile layer uses the required HTTPS URL, visible attribution, normal browser caching and origin Referer. It has no prefetch/offline download function. Public tiles are best-effort; place cards work when tiles fail. Review hosting/contact and usage requirements before public deployment. References checked 2026-10-19: [Leaflet quick start](https://leafletjs.com/examples/quick-start/), [OSM tile usage policy](https://operations.osmfoundation.org/policies/tiles/).

Browser checks verified both click selection and keyboard panning/centre selection. No OpenAI or 2GIS API call was made by map testing; OSM tile traffic occurred. An independent reviewer found no map blocker.
